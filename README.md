# Manga Image Extractor (Chrome Extension)

一个可直接加载到 Chrome 的漫画图片提取插件：
- 从当前网页筛选符合尺寸/比例的图片
- 按页面从上到下排序
- 自动按顺序命名后，**打包成 1 个 ZIP 下载**

## 快速使用
1. 打开 `chrome://extensions/`
2. 开启「开发者模式」
3. 点击「加载已解压的扩展程序」并选择本目录（有 `manifest.json`）
4. 打开漫画网页并先向下滚动，让图片加载
5. 点扩展图标，点击 `1. 提取当前页`
6. 点击 `2. 下载 ZIP`

## 新版特性
- **ZIP 下载**：不再一张张下载，直接得到 `{prefix}_{chapter}.zip`
- **中性灰 + 圆角 UI**：更接近 GPT 风格
- **拖动式尺寸筛选**：最小宽度/高度改为滑块
- **比例可视化**：最小/最大宽高比用可视方框展示

## 参数说明
- 最小宽度（滑块）
- 最小高度（滑块）
- 最小宽高比（滑块）
- 最大宽高比（滑块）

> 宽高比 = 宽 / 高。数值越小，图片越“竖长”。

## 常见问题
- `Could not establish connection. Receiving end does not exist.`
  - 刷新网页后重试（插件已内置自动重试注入）
  - 不要在 `chrome://`、扩展商店、新标签页里使用
  - `file://` 页面请在扩展详情开启“允许访问文件网址”

- 下载失败：`请求失败: 403 ...`
  - 已加入自动兜底：会先在插件后台请求，遇到 401/403 会自动切换到“页面上下文”重试（携带该站点实际请求环境）
  - 对防盗链站点会临时附加 Referer/Origin 请求头（与当前页面一致）提升成功率
  - 下载请求增加了自动重试（网络抖动时会重试 2 次）
  - 若全部图片都无法打包为 ZIP，插件会自动降级为“单图批量下载”（放在同名文件夹）
  - 仍失败时通常是站点防盗链更严格，可先在当前页手动打开该图片确认可访问，再重试打包

- 下载失败：`URL.createObjectURL is not a function`
  - 这是 MV3 Service Worker 环境限制导致
  - 已改成 Data URL 下载 ZIP，不再依赖 `URL.createObjectURL`

- 下载失败：`A listener indicated an asynchronous response ...`
  - 这是后台任务太久导致消息通道被关闭的典型报错（Pixiv 上更容易出现）
  - 现在已改为“先立即确认，再后台处理并回传结果”，避免通道超时

- 下载失败：`全部下载失败。#1 Failed to fetch`
  - 这通常是站点临时开启了更严格跨域/防盗链策略，不是你操作错
  - 插件会在页面主世界重试请求（更接近网页自身请求环境）
  - 如果依然拿不到二进制字节，会自动尝试降级为单图下载

- 提取到 0 张
  - 先滚动页面加载图片
  - 降低最小宽高，或放宽比例范围
