# Manga Image Extractor (Chrome Extension)

一个可直接加载到 Chrome 的漫画图片提取插件：
- 从当前网页筛选符合尺寸/比例的图片
- 按页面从上到下排序
- 按顺序命名并下载到本地

## 你是小白也能用：一步一步来

### 0) 先准备
- 你需要电脑上有 **Chrome 浏览器**。
- 把这个项目文件夹放到你找得到的位置（比如桌面）。

### 1) 安装插件（只要做一次）
1. 在 Chrome 地址栏输入：`chrome://extensions/`
2. 打开右上角 **开发者模式**（开关拨到右边）
3. 点击左上角 **加载已解压的扩展程序**
4. 选择本项目文件夹（里面有 `manifest.json`）
5. 看到 `Manga Image Extractor` 出现在列表里就成功了

### 2) 固定插件图标（方便使用）
1. 点 Chrome 右上角拼图图标（扩展程序）
2. 找到 `Manga Image Extractor`
3. 点旁边的小图钉，把它固定到工具栏

### 3) 开始提取并下载
1. 打开你要下载漫画图片的网页
2. **先往下滚动几屏**，让页面图片尽量加载出来
3. 点击工具栏里的插件图标
4. 先用默认参数，点击 `1. 提取当前页`
5. 看到“提取完成：xx 张”后，点击 `2. 下载结果`
6. 下载会自动开始，不会每张都弹窗

## 下载到哪里了？（重点）
默认会下载到你 Chrome 的默认下载目录：
- Windows 常见是：`C:\Users\你的用户名\Downloads`
- macOS 常见是：`~/Downloads`

你也可以在 Chrome 里改下载目录：
- 打开 `chrome://settings/downloads`

## 命名格式
`{prefix}_{chapter}_{0001}.jpg`

例如：`onepiece_1101_0001.jpg`

## 参数不会调？先用这套
- 最小宽度：`600`
- 最小高度：`800`
- 最小宽高比：`0.55`
- 最大宽高比：`0.90`

如果抓太少：把最小宽高调小一点。  
如果抓到广告图：把最小宽高调大一点。

## 常见问题（小白版）
- 点击提取没反应：
  - 刷新漫画网页后再点一次插件
  - 确认插件还在启用状态（`chrome://extensions/`）
- 出现 `Could not establish connection. Receiving end does not exist.`：
  - 先刷新目标网页，再点插件
  - 确认你不是在 `chrome://`、扩展商店、或新标签页里使用（这些页面不允许注入）
- 下载数量是 0：
  - 先滚动页面让图片加载
  - 把最小宽高调低
- 文件名顺序对不上：
  - 页面里如果有插图广告，建议提高最小宽高过滤

## 说明
- 默认会按 URL 去重并忽略 query 参数，减少重复下载。
- 对使用特殊签名 URL 或复杂反爬的网站，可能需要按站点做定制规则。
